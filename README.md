# موتور برنامه‌ریزی مطالعاتی بر پایهٔ روش ماز

این مخزن یک راهنمای قابل‌انتقال برای ایجنت فراهم می‌کند تا با دریافت **تاریخ/بازه، بودجهٔ آزمون ماز و وضعیت داوطلب**، برنامهٔ مطالعاتی قابل‌اجرا تولید کند.

فرمول از برنامه‌های مطالعاتی واقعی ماز مهندسی معکوس شده است. اعداد ثابت برنامهٔ قدیمی رتبه‌لند ـ مانند ۴۷ ساعت، ۴۹۵ تست و جفت‌درس‌های ثابت ـ قانون ماز محسوب نمی‌شوند.

## نقطهٔ شروع

### برای ایجنت

1. [`AGENTS.md`](AGENTS.md) را بخوان.
2. سپس کل [`MAZ_PLANNING_PLAYBOOK.md`](MAZ_PLANNING_PLAYBOOK.md) را اجرا کن.
3. ورودی را با [`examples/REQUEST_TEMPLATE.yaml`](examples/REQUEST_TEMPLATE.yaml) دریافت کن.
4. برای شناخت دو روش، [`PROGRAM_COMPARISON.md`](PROGRAM_COMPARISON.md) را ببین.

### برای کاربر

این متن را همراه بودجهٔ آزمون به ایجنت بده:

```text
طبق AGENTS.md و MAZ_PLANNING_PLAYBOOK.md برای بازه و آزمون من برنامه بساز.
ردیف بودجه را از فایل ماز کنترل کن، ظرفیت واقعی را حساب کن و هر فرض یا کسری را بنویس.
از فرمول ثابت رتبه‌لند فقط برای ظاهر خروجی استفاده کن، نه برای ساعت و تست.
```

## فایل‌ها

| مسیر | کاربرد |
|---|---|
| [`AGENTS.md`](AGENTS.md) | دستور کوتاه و الزام‌آور برای شروع ایجنت |
| [`MAZ_PLANNING_PLAYBOOK.md`](MAZ_PLANNING_PLAYBOOK.md) | فرمول، الگوریتم، وضعیت‌های تحصیلی، مدل داده، شبه‌کد و QA |
| [`PROGRAM_COMPARISON.md`](PROGRAM_COMPARISON.md) | شرح برنامهٔ رتبه‌لند و ماز و تفاوت‌های دقیق آن‌ها |
| [`examples/REQUEST_TEMPLATE.yaml`](examples/REQUEST_TEMPLATE.yaml) | قالب استاندارد ورودی برای درخواست تازه |

## ورودی‌های ضروری

- تاریخ و سال آزمون یا بازهٔ درخواستی؛
- رشته و وضعیت دهم/یازدهم/دوازدهم/فارغ‌التحصیل؛
- فایل برنامهٔ راهبردی یا بودجهٔ رسمی آزمون؛
- ساعت مدرسه و کلاس‌های ثابت؛
- مباحث قبلاً خوانده‌شده و سطح هر درس؛
- امتحان مدرسه/نهایی و محدودیت‌های فردی.

## خروجی مورد انتظار

- بودجهٔ تصویریِ کنترل‌شده؛
- لقمه‌های جدید و مروری؛
- گزارش ظرفیت، تقاضا و کسری/مازاد؛
- جدول روزانه با زنگ مطالعه، تست، مرور و انعطاف؛
- روز آزمون و تحلیل؛
- قواعد بازچینی شب قبل؛
- گزارش پوشش، فرض‌ها و کنترل کیفیت.

## اصل معماری

```text
موتور برنامه‌ریزی و تخصیص: روش ماز
کنترل ظرفیت و سازگاری: MAZ_PLANNING_PLAYBOOK
قالب نهایی و خوانایی: فرم رتبه‌لند، فقط در صورت نیاز
```

فایل‌های منبع PDF و کتاب‌ها به‌دلیل حجم و حقوق انتشار داخل مخزن نگهداری نمی‌شوند. برای هر آزمون، ایجنت باید فایل بودجه و منابع همان درخواست را دریافت و دوباره کنترل کند.
