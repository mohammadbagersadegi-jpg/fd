# موتورهای برنامه‌ریزی مطالعاتی ماز و رتبه‌لند

این مخزن راهنماهای قابل‌انتقال برای ایجنت فراهم می‌کند تا با دریافت **تاریخ/بازه، بودجهٔ آزمون ماز، کتاب‌های درسی و وضعیت داوطلب**، برنامهٔ مطالعاتی قابل‌اجرا تولید کند.

دو موتور مستقل وجود دارد:

- **رتبه‌لند اصلاح‌شده:** هستهٔ استاندارد ۴۷ ساعت/۴۹۵ تست را حفظ می‌کند، ولی تحلیل تست، ترتیب یادگیری و کنترل امکان‌پذیری را اصلاح می‌کند؛
- **روش ماز:** از برنامه‌های مطالعاتی واقعی ماز مهندسی معکوس شده و ظرفیت‌محور است؛ اعداد ثابت رتبه‌لند قانون ماز محسوب نمی‌شوند.

## نقطهٔ شروع

### برای ایجنت

1. [`AGENTS.md`](AGENTS.md) را بخوان.
2. موتور درخواست را انتخاب کن:
   - [`RANKLAND_PLANNING_PLAYBOOK.md`](RANKLAND_PLANNING_PLAYBOOK.md) برای فرمول اصلی اصلاح‌شدهٔ رتبه‌لند؛
   - [`MAZ_PLANNING_PLAYBOOK.md`](MAZ_PLANNING_PLAYBOOK.md) برای روش ماز.
3. برای شناخت تفاوت دو روش، [`PROGRAM_COMPARISON.md`](PROGRAM_COMPARISON.md) را ببین.
4. در مسیر ماز/ترکیبی، ورودی را با [`examples/REQUEST_TEMPLATE.yaml`](examples/REQUEST_TEMPLATE.yaml) دریافت کن.

### برای کاربر

برای فرمول اصلی اصلاح‌شده:

```text
طبق AGENTS.md و RANKLAND_PLANNING_PLAYBOOK.md برای آزمون من برنامه بساز.
هستهٔ ۴۷ ساعت/۴۹۵ تست را حفظ کن، بودجه و صفحات کتاب را کنترل کن و امکان حل و تحلیل هر باکس را بسنج.
```

برای روش ماز:

```text
طبق AGENTS.md و MAZ_PLANNING_PLAYBOOK.md برای بازه و آزمون من برنامه بساز.
ردیف بودجه را از فایل ماز کنترل کن، ظرفیت واقعی را حساب کن و هر فرض یا کسری را بنویس.
از فرمول ثابت رتبه‌لند فقط برای ظاهر خروجی استفاده کن، نه برای ساعت و تست.
```

## نمونهٔ اجرایی ۱ آبان ۱۴۰۵

نمونهٔ PDF موجود در `outputs/` با این معماری ساخته شده است:

- بودجه و جدید/مروری: روش ماز؛
- ظرفیت: ۵۸ زنگ فرض‌شده، ۵۲ زنگ قطعی و ۶ زنگ انعطاف؛
- تست زیست: دو روز پس از مطالعه؛
- تعداد تست: ثبت واقعی در زنگ ۷۵دقیقه‌ای، نه عدد ثابت؛
- ظاهر: فرم طلایی و خانه‌بندی شبیه خروجی رتبه‌لند؛
- صفحهٔ پنجم: مقایسهٔ مستقیم با نسخهٔ ۹۴ساعته و ۹۹۰تستی قبلی.

این نمونه شخصی‌سازی‌شده نیست و برای مقایسهٔ معماری ساخته شده است. زمین‌شناسی نیز برای همسانی دامنه با خروجی اصلی چهاردرس حذف شده است.

### بازتولید PDF

```bash
python -m venv .venv
.venv/bin/pip install -r requirements-pdf.txt
.venv/bin/python scripts/generate_1aban_hybrid.py
```

## ورودی‌های ضروری

- تاریخ و سال آزمون یا بازهٔ درخواستی؛
- رشته و وضعیت دهم/یازدهم/دوازدهم/فارغ‌التحصیل؛
- فایل برنامهٔ راهبردی یا بودجهٔ رسمی آزمون؛
- ساعت مدرسه و کلاس‌های ثابت؛
- مباحث قبلاً خوانده‌شده و سطح هر درس؛
- امتحان مدرسه/نهایی و محدودیت‌های فردی.

## خروجی مورد انتظار

در هر دو مسیر:

- بودجهٔ تصویری و صفحات چاپیِ کنترل‌شده؛
- بخش‌های جدید و مروری؛
- جدول روزانهٔ مطالعه، تست، مرور و تحلیل؛
- روز قبل آزمون و روز آزمون؛
- گزارش پوشش، فرض‌ها و کنترل کیفیت.

در مسیر ماز، گزارش ظرفیت/تقاضا/کسری نیز الزامی است. در مسیر رتبه‌لند، جمع دقیق ساعت/تست و گزارش امکان‌پذیری باکس‌ها الزامی است.

## اصل معماری

```text
درخواست رتبه‌لند → موتور RANKLAND_PLANNING_PLAYBOOK → قالب رتبه‌لند
درخواست ماز       → موتور MAZ_PLANNING_PLAYBOOK      → قالب دلخواه
درخواست ترکیبی    → هر دو موتور با برچسب منشأ قاعده و بدون اختلاط پنهان
```

فایل‌های منبع PDF و کتاب‌ها به‌دلیل حجم و حقوق انتشار داخل مخزن نگهداری نمی‌شوند. برای هر آزمون، ایجنت باید فایل بودجه و منابع همان درخواست را دریافت و دوباره کنترل کند.
