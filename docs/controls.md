# Controls

| Action | Keyboard | Gamepad | Touch |
|---|---|---|---|
| Move | Arrow keys / WASD | Left stick / D-pad | on-screen pad |
| Attack | J or Z | A (button 0) | ATK |
| Jump | K, X or Space | B (button 1) | JMP |
| Special (electric shock) | L or C | X / Y (buttons 2, 3) | SP |
| Pause | Esc or P | Start / Select | II |
| Start / confirm | Enter | Start | - |
| Mute | M | - | - |
| Debug hitboxes | F2 or ` | - | - |

## Rules worth knowing

* **Combo**: tap attack again while the punch is recovering (before the final
  frame) to chain jab -> cross -> roundhouse. The third hit knocks down.
* **Special**: costs 8 HP, grants 20 ticks of invulnerability and hits every
  enemy within 66 px / 26 px depth. 90 tick cooldown (the amber bar under HP).
* **Jump attack**: press attack while airborne for a dive punch.
* **I-frames**: 38 ticks after a hurt, 45 ticks after getting up.
* **Damage cap per attack**: one attack can damage a given enemy exactly once.
* **Lane limit**: you cannot walk past the screen edges; the camera pushes
  forward when you walk into its dead zone. During a wave the camera locks.
